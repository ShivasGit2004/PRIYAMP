======================================================
 AUTO-PCOS CLASSIFICATION: HOW TO INSTALL AND RUN
======================================================

Welcome to the Auto-PCOS AI Dashboard!
This project has two parts: a Python backend (FastAPI) and a React frontend.

------------------------------------------------------
 STEP 1: INSTALL REQUIRED SOFTWARE
------------------------------------------------------
Before you start, make sure you have the following installed on your computer:
1. Python (version 3.8 or higher) - Download from python.org
2. Node.js (version 16 or higher) - Download from nodejs.org

------------------------------------------------------
 STEP 2: INSTALL PROJECT DEPENDENCIES
------------------------------------------------------
Open a terminal/command prompt inside this project folder ("Auto-Pcos-Classification") and run:

1. Install Python Backend Packages:
   pip install -r requirements.txt

2. Install React Frontend Packages:
   cd frontend
   npm install
   cd ..

------------------------------------------------------
 STEP 3: RUN THE APPLICATION
------------------------------------------------------

EASIEST WAY (Windows Only):
Just double-click the "run.bat" file in the main folder! It will automatically launch both the backend and frontend for you.

MANUAL WAY (Mac/Linux/Windows Terminal):
You will need to open two separate terminal windows.

Terminal 1 (Backend API):
  cd path/to/Auto-Pcos-Classification
  python api.py
  (This will start the backend on http://localhost:8000)

Terminal 2 (Frontend Dashboard):
  cd path/to/Auto-Pcos-Classification/frontend
  npm run dev
  (This will start the frontend on http://localhost:5173)

------------------------------------------------------
 STEP 4: USE THE PLATFORM
------------------------------------------------------
Once both are running, open your web browser and navigate to:
http://localhost:5173

You can upload your ultrasound images in the "Analyze Ultrasound" section!
